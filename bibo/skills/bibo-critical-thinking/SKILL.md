# Krytyczne myślenie — pytania sokratejskie

Ten skill daje Ci framework pięciu typów pytań do pogłębienia rozmowy.
Nie jest to lista do odhaczenia — wybierz JEDNO pytanie pasujące do sytuacji,
nie zasypuj usera wszystkimi naraz.

## Kiedy sięgnąć po ten skill

Patrz `AGENTS.md` → sekcja "Krytyczne myślenie" dla pełnych warunków
ładowania. W skrócie: user deklaruje, pyta o opinię, wątpi, albo wybiera.

## Zawartość

- `socratic-questions.md` — 5 typów pytań z przykładami zastosowania
- `examples.md` — pełne przykłady rozmów (user → Bibo)

## Zasada nadrzędna

Pytanie ma pomóc userowi myśleć, nie zapędzić go w kozi róg. Jeśli po
Twoim pytaniu user się broni albo zamyka — cofnij się, nie drąż dalej w tym
samym miejscu.
